Writer — Features

  • Multiple document tabs
  • Auto-save on every keystroke
  • Writing goals with lock option
  • Document outline navigation
  • Word frequency analysis
  • Comments with text highlighting
  • Footnotes with click-to-highlight
  • Auto-generated table of contents
  • Document templates (built-in + custom)
  • Version history with restore
  • Special characters & emoji picker
  • Writing session timer (Pomodoro)
  • Distraction-free Zen Mode
  • Quick format menu (Alt + Right-click)
  • Smart typography (auto-convert quotes, symbols)
  • Custom auto-correction rules
  • Page setup (A4, Letter, Legal, A3, A5, B5)
  • Custom header & footer with page numbers
  • Cloud sync via Syncthing (File System Access API)
  • Ctrl+Click links open in new tab
  • Import .txt, .md, .rtf, .html, .docx, .orosdoc
  • Export to .txt, .md, .html, .rtf, .pdf, .docx, .orosdoc
  • Database export (settings + all documents)
