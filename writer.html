Cloud Sync

Automatically back up your entire database to a local folder synced by Proton Drive, Syncthing, Dropbox, or any cloud desktop app.
Works offline. Your data never touches a third-party server — it stays in a file you control.

Checking…

Manually restore data from the sync file. This replaces ALL current data.

IndexedDB Fallback

An automatic copy is kept in the browser's IndexedDB every 5 minutes, even without a sync folder.
This survives cookie clears and browser restarts, but not a full data wipe.

Syncthing Workflow

  1. Desktop: Connect sync folder (e.g. Documents/oros-sync)
  2. Syncthing: Share that folder with your Android device
  3. Desktop: Data syncs automatically every 5 min
  4. Android: Writer → Import Database → select oros-writer-sync.json
  5. Android → Desktop: Export Database, place file in synced folder, use Restore from Cloud
