orOS for Windows and Linux (installer)

Available

Install orOS on your computer with its own private browser (ungoogled-chromium, no Google). It works offline, keeps itself up to date, and keeps its data on this computer; Dropbox sync carries it to your other devices.

Windows 10/11: no administrator rights needed, orOS goes into the Start menu. The file is not signed yet, so SmartScreen may warn the first time: More info › Run anyway. Also with Scoop: scoop bucket add oros https://github.com/koulaxizis/oros-portable, then scoop install oros.

Not sure? Take the full edition. Pick lite only for a small download or a small stick.

Stick: 32 GB or more recommended (64 GB is ideal and usually faster), 8 GB minimum. Format it as NTFS (on Linux, exFAT and FAT32 cannot hold the browser's data), unzip, copy everything inside the orOS-Portable folder to the stick, then double-click orOS.exe (Windows) or run ./orOS (Linux). Optional: orOS-sticktest checks whether a stick is fast enough.

orOS Live USB (bootable)

Beta

Start any PC straight into orOS, with no Windows or Linux needed. Write the ISO (about 1.4 GB) to a USB stick (8 GB or more) with Rufus or balenaEtcher, then boot from it (F12/F11/Esc boot menu; on Acer it may be listed as “Linpus lite”). With Rufus, set “Persistent partition size” so your data stays on the stick. The System button has Wi-Fi, sound, Restart, Shut down, monthly system updates and installing orOS on the computer; the Internet button opens a normal browser window. Secure Boot supported. For 64-bit Intel/AMD PCs; not for Macs with Apple chips.

Beta 0.1.0-beta.5: download the ISO (about 1.5 GB). New: orOS Bridge inside, scanners, and optional encrypted data on the stick (a passphrase at start). It is for testing: on some PCs the very first start shows a white screen for a moment, and orOS then starts again by itself. System › Problem report helps us find the cause.

orOS Drive (your folders in the Vault)

Beta

Mirror chosen folders of your Windows or Linux computer into your encrypted orOS Vault, both ways. They appear in orOS under Files › orOS Drive and download only when you open them. It can also show the whole orOS disk as a folder (in Windows Explorer, or ~/orOS on Linux).

Sign in with the Dropbox account orOS syncs with and unlock with your sync passphrase: Dropbox sees neither file names nor contents. Windows 10/11 (x64 and ARM64): the setup needs no administrator rights. The file is not signed yet, so SmartScreen may warn the first time: More info › Run anyway.

Beta 0.3.1: download for Windows (setup, about 7 MB) · Linux .deb for amd64 or arm64. Portable Windows zips, Linux tarballs and the source code are on GitHub. Besides Dropbox, it can keep the Vault on your own Nextcloud or WebDAV server.

Android (Beta): back up folders of the phone, keep files offline, share files to orOS, back up new camera photos, and see the whole orOS disk in the phone's Files app. Install it from the orOS F-Droid repository (F-Droid, Droid-ify or Obtainium keep it up to date) or download the APK.

orOS Bridge (your plugins in Studio)

Beta

Use the VST3 and CLAP plugins installed on your computer, the ones you bought too, in orOS Studio. The bridge runs your plugins on the computer; Studio sends a track through one and gets it back as a new audio track that plays everywhere.

It also opens your sound card, so Studio records through it: pick the inputs to record, and the song plays and records on the card's own clock, with no drift. Windows: WASAPI, shared or exclusive, and ASIO® drivers (with oros-bridge-asio.dll next to the bridge, in the Windows zip; a separate GPLv3 module). Linux: JACK, PipeWire/PulseAudio and ALSA. In Studio's settings, under Sound card, set Record and play through to orOS Bridge.

Already inside orOS: the orOS installer for Windows and Linux, orOS Portable (Full) and orOS Live USB bring the bridge with them. It starts with orOS, orOS shows its code, and it is updated together with orOS, so there is nothing more to download.

On its own: Windows 10/11 (x64), no setup: run it and keep its window open while you use Studio (it can also sit in the tray). Linux (x64): the .deb, .rpm or AppImage give it a window and a tray icon; the tar.gz runs as ./oros-bridge in a terminal. Then in a track's settings press Plugin on this computer and type the code the bridge shows, once. When a new version is out, the bridge says so in its window and tray and updates in one click, after checking every file against the release's checksums. It listens only on this computer and only orOS can talk to it. Not signed yet: Windows SmartScreen may ask once (More info › Run anyway). Free, MIT.

orOS browser add-on

Install by hand

Fill your orOS Passwords on any site: logins, 2FA codes, cards, identities and addresses. It also saves the page you are on to orOS Bookmarks and searches orOS from the address bar. For Chrome, Edge, Brave and Firefox. Your vault stays encrypted; only the key is kept in the browser's memory until it locks.

Download the add-on (.zip)

Chrome, Edge, Brave: unzip it into a folder you keep. Open chrome://extensions (edge://extensions, brave://extensions), turn on Developer mode, press Load unpacked and choose that folder. Pin the orOS icon to the toolbar. To update, unzip the new zip over the same folder and press the reload arrow on the add-on.

Firefox: unzip it, open about:debugging#/runtime/this-firefox, press Load Temporary Add-on and choose manifest.json. Firefox removes it when it closes, until the add-on is on addons.mozilla.org.

First use: open orOS in a tab and press the orOS icon (or Ctrl+Shift+L). Press Allow access to orOS once so it can copy your encrypted vault, then unlock with your master password. On a site, choose an entry and it fills the form. If a card number sits in a payment frame from another site, the add-on names that site and asks first.

orOS Bridge (τα plugins σου στο Studio)

Beta

Χρησιμοποίησε στο orOS Studio τα VST3 και CLAP plugins που είναι εγκατεστημένα στον υπολογιστή σου, και όσα έχεις αγοράσει. Η γέφυρα τρέχει τα plugins στον υπολογιστή· το Studio στέλνει ένα κανάλι μέσα από ένα plugin και το παίρνει πίσω ως νέο κανάλι ήχου που παίζει παντού.

Ανοίγει και την κάρτα ήχου σου, ώστε το Studio να ηχογραφεί μέσα από αυτήν: διαλέγεις ποιες εισόδους θα γράψεις, και το τραγούδι παίζει και γράφει με το ρολόι της ίδιας της κάρτας, χωρίς απόκλιση. Windows: WASAPI, κοινόχρηστο ή αποκλειστικό, και drivers ASIO® (με το oros-bridge-asio.dll δίπλα στη γέφυρα, μέσα στο zip για Windows· ξεχωριστό module υπό GPLv3). Linux: JACK, PipeWire/PulseAudio και ALSA. Στις ρυθμίσεις του Studio, στην Κάρτα ήχου, βάλε την Ηχογράφηση και ακρόαση μέσω στο orOS Bridge.

Ήδη μέσα στο orOS: η εγκατάσταση του orOS για Windows και Linux, το orOS Portable (Πλήρες) και το orOS Live USB φέρνουν τη γέφυρα μαζί τους. Ξεκινά μαζί με το orOS, το orOS δείχνει τον κωδικό της και ενημερώνεται μαζί με το orOS, οπότε δεν χρειάζεται να κατεβάσεις τίποτε άλλο.

Μόνο του: Windows 10/11 (x64), χωρίς εγκατάσταση: άνοιξέ το και κράτα το παράθυρό του ανοιχτό όσο χρησιμοποιείς το Studio (μπορεί να μένει και στη γραμμή εργασιών, δίπλα στο ρολόι). Linux (x64): το .deb, το .rpm ή το AppImage του δίνουν παράθυρο και εικονίδιο δίπλα στο ρολόι· το tar.gz τρέχει ως ./oros-bridge σε τερματικό. Μετά στις ρυθμίσεις ενός καναλιού πάτησε Plugin σε αυτόν τον υπολογιστή και πληκτρολόγησε μία φορά τον κωδικό που δείχνει η γέφυρα. Όταν βγει νέα έκδοση, η γέφυρα το λέει στο παράθυρο και στο εικονίδιό της και ενημερώνεται με ένα κλικ, αφού ελέγξει κάθε αρχείο με τα checksums της έκδοσης. Ακούει μόνο σε αυτόν τον υπολογιστή και μόνο το orOS μπορεί να του μιλήσει. Δεν είναι ακόμη υπογεγραμμένο: το Windows SmartScreen μπορεί να ρωτήσει μία φορά (Περισσότερες πληροφορίες › Εκτέλεση οπωσδήποτε). Δωρεάν, MIT.

Πρόσθετο browser orOS

Χειροκίνητη εγκατάσταση

Συμπληρώνει τα Passwords του orOS σε κάθε site: λογαριασμούς, κωδικούς 2FA, κάρτες, ταυτότητες και διευθύνσεις. Αποθηκεύει επίσης τη σελίδα που βλέπεις στους Σελιδοδείκτες του orOS και ψάχνει στο orOS από τη γραμμή διευθύνσεων. Για Chrome, Edge, Brave και Firefox. Η κρύπτη μένει κρυπτογραφημένη· μόνο το κλειδί κρατιέται στη μνήμη του browser ώσπου να κλειδώσει.

Λήψη του πρόσθετου (.zip)

Chrome, Edge, Brave: αποσυμπίεσέ το σε έναν φάκελο που θα κρατήσεις. Άνοιξε το chrome://extensions (edge://extensions, brave://extensions), άναψε τη Λειτουργία προγραμματιστή, πάτα Φόρτωση αποσυμπιεσμένου και διάλεξε τον φάκελο. Καρφίτσωσε το εικονίδιο του orOS στη γραμμή εργαλείων. Για ενημέρωση, αποσυμπίεσε το νέο zip στον ίδιο φάκελο και πάτα το βελάκι επαναφόρτωσης στο πρόσθετο.

Firefox: αποσυμπίεσέ το, άνοιξε το about:debugging#/runtime/this-firefox, πάτα Φόρτωση προσωρινού πρόσθετου και διάλεξε το manifest.json. Ο Firefox το αφαιρεί όταν κλείσει, ώσπου το πρόσθετο να μπει στο addons.mozilla.org.

Πρώτη χρήση: άνοιξε το orOS σε μια καρτέλα και πάτα το εικονίδιο του orOS (ή Ctrl+Shift+L). Πάτα Άδεια πρόσβασης στο orOS μία φορά ώστε να αντιγράψει την κρυπτογραφημένη κρύπτη σου και ξεκλείδωσε με τον κύριο κωδικό. Σε ένα site διάλεξε μια εγγραφή και συμπληρώνεται η φόρμα. Αν ο αριθμός κάρτας είναι σε πλαίσιο πληρωμής άλλου site, το πρόσθετο λέει ποιο είναι και ρωτά πρώτα.
