# Μετάφραση του orOS

Το orOS κυκλοφορεί στα αγγλικά και στα ελληνικά. Κάθε άλλη γλώσσα είναι ένας
φάκελος με αρχεία κειμένου, `i18n/<κωδικός>/`, που γράφονται χωρίς να
αγγίξεις κώδικα. Ό,τι δεν έχει μεταφραστεί ακόμα εμφανίζεται στα αγγλικά,
οπότε μια γλώσσα μεγαλώνει μία εφαρμογή τη φορά. English: [README.md](README.md).

## Τι έχει ο φάκελος μιας γλώσσας

- `shell.js`: η γραμμή, το μενού, οι ειδοποιήσεις, οι διάλογοι.
- `settings.js`, `help.js`, και ένα αρχείο για κάθε εφαρμογή, με το όνομα του φακέλου της.
- `help/<εφαρμογή>.txt` και `help/topics/<σελίδα>.txt`: οι σελίδες βοήθειας.
- `STATUS.md` (τι μένει) και `manifest.json` (τι κατεβαίνει για offline): τα γράφει script.

Ένα αρχείο μοιάζει έτσι και δεν έχει τίποτε άλλο:

```js
orosPack("de", "notes", {
 "tree.empty": "Noch keine Seiten",
 "page.count": "{n} Seiten"
});
```

## Οι κανόνες (τους ελέγχουν τα tests)

- Μόνο ζεύγη `"κλειδί": "κείμενο"` σε διπλά εισαγωγικά (JSON). Κανένας κώδικας.
- Κάθε `{όνομα}` μένει ακριβώς όπως στα αγγλικά: εκεί μπαίνει αριθμός ή όνομα.
- Τα ίδια HTML tags με τα αγγλικά (`<b>…</b>`), ούτε περισσότερα ούτε λιγότερα.
- Μόνο κλειδιά που έχει ο αγγλικός πίνακας. Ό,τι δεν μεταφράζεις ακόμα το αφήνεις έξω, δεν αντιγράφεις τα αγγλικά.
- Τα ονόματα προϊόντων (Dropbox, orOS) μένουν ως έχουν.
- Οι σελίδες βοήθειας κρατούν τα σημάδια της αγγλικής (`#`, `##`, `-`, `` ` ``, `[[…]]`, `[…](app:…)`).

Μια τιμή που σπάει κανόνα δεν εμφανίζεται ποτέ: το orOS δείχνει την αγγλική
γραμμή, και τα tests του pull request λένε τι να διορθωθεί.

## Μετάφραση μέσα στο orOS

Ο πιο εύκολος τρόπος: στο orOS άνοιξε Ρυθμίσεις › Γλώσσα και αναζήτηση ›
Βοήθησε στη μετάφραση. Διαλέγεις γλώσσα και μέρος του orOS, και κάθε γραμμή
δείχνει τα αγγλικά και τα ελληνικά με ένα πεδίο για τη δική σου, πρώτα όσες
δεν έχουν μεταφραστεί. Ό,τι γράφεις μένει στη συσκευή σου και φαίνεται αμέσως
στο orOS (`Δοκίμασέ το`). Οι γραμμές που σπάνε κάποιον κανόνα σημειώνονται
και μένουν στα αγγλικά. Η `Λήψη αρχείου` σου δίνει το έτοιμο `<app>.js` για
τα παρακάτω βήματα.

## Πώς στέλνεις μετάφραση

Χωρίς git: ανοίγεις το αρχείο στο GitHub, πατάς το μολύβι (Edit), γράφεις
και πατάς «Propose changes». Το GitHub ανοίγει μόνο του το pull request.
Με git: `node .github/i18n/new-language.js`, `node .github/i18n/coverage.js`
και τα tests, όπως στο [README.md](README.md). Κάθε μετάφραση μπαίνει μόνο με
pull request που ελέγχει ο συντηρητής.

## Δοκιμή

Άνοιξε το orOS με `?lang=<κωδικός>`, π.χ. `https://useoros.online/?lang=de`.
Μια νέα γλώσσα δεν φαίνεται στη λίστα γλωσσών μέχρι να μεταφραστούν το shell,
οι Ρυθμίσεις και η Βοήθεια. Μετά φαίνεται, με σημείωση «μερική μετάφραση»
μέχρι να μεταφραστούν όλες οι εφαρμογές.
