## Purpose
orOS is a privacy-first creative toolkit for artists. All tools work completely offline with zero tracking.

## Core Products
1. Writer (writer.html) — Rich text editor with autosave, writing goals, document outline, word frequency analysis
2. Case Converter (converter.html) — 10 text transformation modes + Greek accent removal
3. Kanban (kanban.html) — Multi-board kanban with drag & drop cards/columns, labels, due dates, search, filters
4. Notes (notes.html) — Wiki-style notes with [[wikilinks]], Markdown rendering, folder hierarchy, search

## Privacy Principles
- No cookies, no tracking, no analytics
- All data stored client-side (localStorage/IndexedDB)
- No external API calls
- Open source (MIT License)

## Languages Supported
English, Greek

## Technical Details
- Architecture: Vanilla JavaScript (no frameworks)
- Hosting: GitHub Pages
- PWA: Yes (installable, offline-capable)
- Service Worker: Cache-first strategy
- Fonts: Local Nunito, ForkAwesome icons
