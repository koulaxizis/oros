# Keyboard shortcuts
orOS has a set of keyboard shortcuts that work everywhere: on the desktop and inside most apps. They all use the same three keys plus one letter: [[Ctrl+Alt+Shift]].

## All shortcuts
- [[Ctrl+Alt+Shift+P]]: `Force push to cloud`
- [[Ctrl+Alt+Shift+O]]: `Force pull from cloud`
- [[Ctrl+Alt+Shift+S]]: `Export backup to folder now`
- [[Ctrl+Alt+Shift+X]]: `Export database`
- [[Ctrl+Alt+Shift+I]]: `About orOS + shortcuts`
- [[Ctrl+Alt+Shift+U]]: `Check for updates`
- [[Ctrl+Alt+Shift+L]]: `Switch language`
- [[Ctrl+Alt+Shift+R]]: `Connect / reconnect cloud sync`
- [[Ctrl+Alt+Shift+C]]: `Open Calculator`
- [[Ctrl+Alt+Shift+F]]: `Search apps and data` (opens the menu with the cursor in its search box)
- [[Ctrl+Alt+Shift+H]]: `Help for the open app`
- [[Ctrl+Alt+Shift+T]]: `Start / stop the Timesheet timer`
- [[Ctrl+Alt+Shift+A]]: `Open the Assistant`
- [[Ctrl+Alt+Shift+Y]]: `Open Today, the summary of your day`
- [[Ctrl+Alt+Shift+N]]: `New sticky note`
- [[Ctrl+Alt+Shift+K]]: `Command bar`
- [[Ctrl+Alt+Shift+W]]: `Switch between open apps (multitasking)`
- [[Ctrl+Alt+Shift+E]]: `Overview: search, open apps, recent files`
- [[Ctrl+Alt+Shift+Q]]: `Ask the Assistant in a small window`
- [[Ctrl+Alt+Shift+M]]: `Quick settings`
- [[Ctrl+Alt+Shift+V]]: `Clipboard history`
- [[Ctrl+Alt+Shift+.]]: `Emoji`
- [[Ctrl+Alt+Shift+G]]: `Take a screenshot (orOS USB)`
- [[Ctrl+Alt+Shift+J]]: `Screen reader on / off (orOS USB)`
- [[Ctrl+Alt+Shift+D]]: `Switch screens: extend, duplicate or one only (orOS USB)`

## What each one does
### Sync and backup
- **Push** sends your data to the cloud now, and **pull** brings the latest from the cloud now. Both need [sync](help:t/sync) to be connected; otherwise you'll see `Cloud sync is not connected`.
- **Export backup to folder now** writes a backup file into your backup folder. This needs `Automatic backup` in `Settings` to be on and a `Backup folder` chosen. In browsers that can't use a backup folder (such as Firefox, Safari and phones), it saves a backup file instead, like `Export backup file`.
- **Export database** saves all your orOS data to a file, the same as `Export backup file` in `Settings`. See [Backup](help:t/backup).
- **Connect / reconnect cloud sync** starts the Dropbox connection if you aren't connected. If you are, it asks again for permission to use your backup folder, when the browser has taken it away.

### Everything else
- **About orOS + shortcuts** opens the About window, with the version, the online services, this list of shortcuts and the [factory reset](help:t/reset). Press it again or [[Esc]] to close it.
- **Check for updates** looks for a new version right away. See [Install](help:t/install).
- **Switch language** swaps between English and Greek.
- **Open Calculator** opens [Calculator](app:calculator).
- **Start / stop the Timesheet timer** opens [Timesheet](app:timesheet) and starts the timer, or stops the one that is running. While a timer runs, the top bar shows how long it has been going; click it to open Timesheet.
- **New sticky note** puts a new [sticky note](app:stickies) on the desktop, ready for you to type. On a phone, or from inside an app, it opens the note in a window.
- **Command bar** opens a small bar over the screen where you type a command such as `dentist tomorrow 10` or `buy milk`. Press the shortcut again to close it. See [The menu](help:t/menu#commands).
- **Switch between open apps** lists the apps that are open with [multitasking](help:a/settings) on: the one in front and the ones waiting in the background. The app you left last is already selected, so the shortcut and then [[Enter]] takes you straight back to it. With multitasking off, it tells you where to turn it on.
- **Clipboard history** shows what you copied in orOS apps, when you turned it on in Settings. See [Privacy](help:t/privacy).
- **Emoji** opens the emoji picker: search in English, Greek or German, or pick from a group. The emoji goes into the text field you were last in, in the app on screen, and the picker stays open for more ([[Esc]] closes it); with no such field it is copied. `Emoji` in Quick settings opens it too.
- **Overview** shows on one screen the search field, your open apps, your recent files and a small System strip (memory, storage, sync). Start typing to search: the text goes to the menu search. See [The menu](help:t/menu#overview).
- **Help for the open app** opens Help at the page of the app you are using. On the desktop, it opens Help's start page.

## Change a shortcut
In [Settings](app:settings) › `System` › `Keyboard shortcuts`, `Change` next to a shortcut waits for its new key: press a letter or a digit (without [[Ctrl]], [[Alt]] or [[Shift]]; [[Esc]] cancels). The three keys [[Ctrl+Alt+Shift]] always stay the same. If another shortcut already has that key, orOS tells you which one, and `Swap` gives it the old key of the one you are changing. `Off` turns a shortcut off, so the app you are in can use that key for itself. `Default` brings back one shortcut's own key, and `Reset all to the defaults` brings back all of them. Your keys follow you to all your devices, and the About window and the tooltips show them.

## Mac and keyboard layouts
On a Mac, use [[Control+Option+Shift]] plus the letter. [[Cmd]] works in place of [[Control]] too. The About window shows the keys as ⌃⌥⇧.

Shortcuts follow the key's position, not the letter it types, so they work the same with a Greek keyboard layout.

## When shortcuts don't work
- Shortcuts don't fire while you are typing in a text box, so they never get in the way of what you write. Click outside the box first.
- A few apps don't pass shortcuts on yet. Go back to the desktop and try again.

> Apps have shortcuts of their own as well. You'll find them on each app's Help page.
